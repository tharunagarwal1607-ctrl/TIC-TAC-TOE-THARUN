# ❌ Tic-Tac-Toe with AI ⭕

A simple and interactive Tic-Tac-Toe game where a human player competes against a computer-controlled AI.

## 📌 Project Description

This project implements a classic Tic-Tac-Toe game using HTML, CSS, and JavaScript.

The player uses **X**, while the computer uses **O**.

The computer opponent uses the **Minimax algorithm** to select its moves.

## 🚀 Features

* Human vs Computer gameplay
* Minimax AI opponent
* Clear 3 × 3 game board
* Win detection
* Loss detection
* Draw detection
* Winning combination highlighting
* Score tracking
* New Game button
* Responsive design

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Minimax Algorithm

## 🧠 How the AI Works

The AI uses the Minimax algorithm.

1. The computer checks all possible available moves.
2. It simulates each move.
3. It checks possible future player and computer moves.
4. Winning moves receive a high score.
5. Losing moves receive a low score.
6. Draws receive a score of zero.
7. The computer selects the move with the highest score.

## ▶️ How to Run

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Open `index.html`.
4. Run it using a browser.

You can also use the **Live Server** extension in VS Code.

## 🎮 Controls

* Click an empty square to place **X**.
* The computer automatically places **O**.
* Continue until there is a winner or draw.
* Click **New Game** to play again.
